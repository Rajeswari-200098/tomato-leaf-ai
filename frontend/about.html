About the Project

Deep Learning-Based Tomato Leaf Disease Detection and Classification Using Computer Vision

Problem statement

Tomato diseases cause major yield losses. Manual inspection is slow, subjective and needs expertise, so early detection is often missed.

Objectives

  • Classify tomato leaves into 10 classes
  • Report prediction confidence
  • Give symptoms, causes and prevention
  • Provide an easy web interface

Methodology

  • PlantVillage tomato dataset
  • 70/15/15 train/validation/test split
  • Augmentation and MobileNetV2 transfer learning
  • Evaluation on held-out test images

Technologies

  • Python, TensorFlow/Keras
  • Flask REST API
  • Pillow, NumPy
  • HTML, CSS, JavaScript

Applications in smart agriculture

  • Early disease warning for farmers
  • Reduced unnecessary pesticide use
  • Mobile field diagnosis
  • Support for extension workers

Limitations

PlantVillage images are taken in controlled conditions, so accuracy on real field photos may be lower. The model only knows these 10 classes. Results support, not replace, expert diagnosis.
